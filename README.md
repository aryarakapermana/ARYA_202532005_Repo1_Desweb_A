# Mangrove Birdwatch Jakarta

Static multi-page website (HTML5 only, no CSS) for Laprak 1 Desain Web.

- Author: Arya Raka Permana (202532005)
- Topic: beginner's guide to birdwatching in the mangrove forests of North Jakarta

## Pages
| File | Content |
|------|---------|
| `index.html` | Home page, site overview |
| `spesies.html` | Article and table of six bird species |
| `panduan.html` | Birdwatching guide (lists, aside) |
| `lapor.html` | Observation form (semantic form with validation) |

Images are in `images/` (self-made illustrations).

## Run locally
Open `index.html` in any browser. No build step is needed.
